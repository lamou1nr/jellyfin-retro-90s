# Changelog

## v1.2.0 (2026-11-15)

First public release.

- Base layer `retro.css`: VT323 titles, square corners, TV focus styles, Amber palette.
- Palettes: Memphis (`retro-memphis.css`) and Arcade (`retro-arcade.css`).
- Optional layers: Memphis shapes beside section titles, "Now Showing" banner on the home
  tab, CRT overlay (scanlines, vignette, rounded corners) that is removed during playback.
- Docker wrapper for the official Jellyfin image that serves the files from Jellyfin itself.
