Everything in this repository was written for this theme except the items below.

## Fonts

The files in `theme/fonts/` are licensed under the SIL Open Font License 1.1. The license
texts are in the same folder (`LICENSE-vt323.txt`, `LICENSE-ibm-plex-mono.txt`).

| Font | Copyright | Source package | Files used |
|---|---|---|---|
| VT323 | Copyright 2011, The VT323 Project Authors | `@fontsource/vt323` 5.3.0 (npm) | `vt323-latin-400-normal.woff2`, `vt323-latin-ext-400-normal.woff2` |
| IBM Plex Mono | Copyright 2017 IBM Corp. | `@fontsource/ibm-plex-mono` 5.3.0 (npm) | `ibm-plex-mono-{latin,latin-ext}-{400,500,600,700}-normal.woff2` |

The font files are unmodified copies from those packages. The `unicode-range` values in
`theme/retro.css` are copied from each package's `400.css`.

Reading text uses Noto Sans, which Jellyfin's web client already ships. This repository does
not include it.
